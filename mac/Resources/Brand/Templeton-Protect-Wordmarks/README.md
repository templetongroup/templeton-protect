# Templeton Protect wordmarks

All wordmarks use the bundled Templeton swirl without redrawing it and pair it
with the exact text `TEMPLETON PROTECT` in Avenir Next Heavy.

## Horizontal — 3600 × 640

- `horizontal-navy-transparent.png` — Midnight Navy ink, transparent background
- `horizontal-champagne-transparent.png` — Champagne ink, transparent background
- `horizontal-navy-on-champagne.png` — Midnight Navy ink on Champagne
- `horizontal-champagne-on-navy.png` — Champagne ink on Midnight Navy

## Stacked — 2400 × 2400

- `stacked-navy-transparent.png` — Midnight Navy ink, transparent background
- `stacked-champagne-transparent.png` — Champagne ink, transparent background
- `stacked-navy-on-champagne.png` — Midnight Navy ink on Champagne
- `stacked-champagne-on-navy.png` — Champagne ink on Midnight Navy

Palette:

- Midnight Navy: `#192A56`
- Champagne: `#F7D794`

Regenerate the complete set from the repository root with:

```sh
swift mac/make-wordmark.swift
```
