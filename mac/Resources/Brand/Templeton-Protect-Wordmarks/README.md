with the exact text `TEMPLETON PROTECT` in Avenir Next Heavy.

Regenerate the complete set from the repository root with:

```sh

```

## Text only — no swirl

Radiant's wordmark is pure type: `RADIANT` set heavy and wide with no mark
beside it. These are Protect's equivalent, in the champagne, for the places a
lockup would be too much — a page hero where the icon already appears, a header,
a footer, anywhere the swirl is redundant.

Generated by `mac/make-text-wordmark.swift`, which is separate from
`mac/make-wordmark.swift` on purpose: that one builds the swirl-plus-type
lockups above and belongs to a different hand. Neither script overwrites the
other's output.

### `TEMPLETON PROTECT` — 1800 × 300

For anywhere the company has to be said too.

- `text-templeton-protect-champagne-transparent.png`
- `text-templeton-protect-champagne-on-navy.png`
- `text-templeton-protect-navy-transparent.png`

Tracking is set slightly negative (−0.015 em). Heavy geometric caps at default
spacing read as a row of separate letters rather than one word; pulling them
together is what makes it a mark.
